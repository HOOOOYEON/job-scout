# 五维评分模型

一个岗位值不值得投，不能只看「跟我会的东西像不像」。本模型把判断拆成六个维度，
每个维度单独打分（0–100），再按权重合成综合分。

## 综合分公式

```
综合分 = 匹配分 × 25%
       + 公司分 × 20%
       + 工作分 × 20%
       + 福利分 × 15%
       + 应届分 × 10%
       + 口碑分 × 10%
```

结果取整到 0–100。**默认及格线 80 分**，低于及格线的岗位不进入当日清单。

及格线可以按自己的处境调。应届、方向明确、竞争激烈时可以调高；转行、岗位稀少时可以调低，
但**调过一次之后要固定住**，否则每天的清单没有可比性。

## 六个维度怎么打分

### 1. 匹配分（权重 25%）

岗位 JD 和候选人真实经历的贴合度。权重最高，因为它直接决定简历过不过初筛。

打分只看**有简历证据的**能力。掌握程度按这个梯度换算：

| 掌握程度 | 分数区间 | 判断依据 |
|---|---|---|
| 独立做过、有产出 | 85–100 | 能拿出作品或数据，能讲清决策过程 |
| 在指导下完成过 | 70–84 | 参与过完整流程，但关键决策不是自己做的 |
| 课程/项目里练过 | 55–69 | 有练习产物，没有真实场景 |
| 用过、了解概念 | 40–54 | 能说清是什么，没实操 |
| 只听过 | 0–39 | 不算能力 |

**重要：不要把「接触过」当「熟练」。** 把了解写成熟练，面试第一轮就会被问穿，
这是最亏的一种虚高。

### 2. 公司分（权重 20%）

公司本身的正规程度，与个人无关，客观打。

- 上市 / 知名融资 / 规模稳定 → 高分
- 小微初创、信息稀薄 → 中低分
- 有欠税、诉讼记录 → **不直接否决**。

判断标准是「管不管得到我」：只要不影响本人薪资发放与社保缴纳，照常推荐。
真正的红线只有两条：**拖欠工资**、**试用期不缴社保**。

### 3. 工作分（权重 20%）

工作内容本身的价值：与自身技术栈的契合度、这份经历在简历上的含金量、后续成长空间。

一个判断技巧：问自己「干满一年后，这段经历能不能写进简历并撑起一段面试对话」。
如果答案是不能，分数就不该高。

### 4. 福利分（权重 15%）

五险一金、双休、补充商业保险、年假、餐补车补等。

注意区分**「加分项」和「否决项」**：

- 五险一金、薪资水平 → 加分项，有问题不否决，只扣分
- 双休、通勤时长 → **否决项**，不达标直接淘汰，见 `hard-gates.md`

这个区分很关键。很多人把「薪资不够高」当成淘汰理由，结果把本来能去的岗位全筛掉了。

### 5. 应届分（权重 10%）

对应届生是否友好：是否走校招、有没有培养体系、转正率如何、容不容忍零经验。

社招岗但写「接受应届」的，分数不该低于纯校招岗 —— 有时候入口更真实。

### 6. 口碑分（权重 10%）

在职与离职员工的真实评价：加班强度、管理风格、薪资是否兑现。

检索方法和归属确认规则见 `reputation.md`。**搜不到就按中位数给分（60），不要瞎猜。**

## 评分纪律

- **每一项都要能说出理由**。打不出理由的分数就是拍脑袋，会在复盘时误导自己。
- **不要因为一个维度特别亮就给整体高分**。权重就是用来压制这种冲动的。
- **同一批岗位用同一把尺子**。今天严明天松，清单就没有意义了。

`scripts/score.py` 实现了这套算法，直接传维度分进去即可，不要手算。
