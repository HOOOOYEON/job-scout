# 公司口碑检索与归属确认

口碑是判断「这家公司值不值得去」最直接的信息，也是最容易出错的一环 ——
不是因为搜不到，而是因为**搜到的东西未必属于这家公司**。

## 铁律：确认归属才能采信

**搜索结果必须确认归属公司，才能写进口碑判断。**

无法确认归属的评价，一律标「未查到该公司专属评价」，并按其维度给中位数分。

### 什么情况算「无法确认归属」

- **公司名相似但不同**。中文公司名高度相似，「某柠」和「某初柠」可能是两家完全无关的公司。
- **分公司 / 关联公司**。评价可能来自集团其他分部或同名关联主体，不能直接套用。
- **评价页没写公司全称**。只写了简称或品牌名，且无法与目标公司对应。
- **招聘平台上的匿名评价**，未显示所属公司，只是搜索关键词命中。

### 常见陷阱

搜索引擎会把「公司名 + 评价」的关键词命中结果直接返回，但命中的可能只是页面上
出现了相似的字，而不是真的在评价这家公司。**看到结果后必须先确认页面上的公司主体，
再决定是否采信。**

绝不为了让日报显得「信息完整」而把不明归属的负面评价安到目标公司头上。
这比写「未查到」糟糕得多 —— 用户可能因此放弃一家其实不错的公司。

## 检索渠道

按覆盖度排，建议至少覆盖前三个：

1. **职场社交平台**（脉脉等）—— 在职员工发言，时效性好
2. **招聘平台的员工评价区** —— 结构化的优缺点评价
3. **公司评价社区**（看准网、职Q 等）—— 历史积累的评价量较大
4. **内容社区**（小红书等）—— 常有一手工作体验分享，关键词可搜「<公司名> 上班」「<公司名> 真实体验」
5. **企业信息平台** —— 查工商信息、司法风险、经营异常，属于客观数据不是口碑

## 关注什么

口碑检索要回答的是具体问题，不是泛泛看「好不好」：

- **加班强度**：是否常态加班，有没有加班费
- **薪资兑现**：绩效是否打折，年终奖是否如实发放
- **社保缴纳**：是否足额、是否转正才缴、有没有按最低基数缴
- **管理风格**：是否 PUA、汇报层级是否混乱
- **离职率**：是否常年大量招人（往往侧面反映留不住人）

其中**社保缴纳**和**薪资兑现**两项要特别留意，它们是唯二能构成否决理由的红线。

## 输出格式

口碑部分按这个格式写：

```
口碑（3 条相关评价，2 条可确认归属）
- 可确认：加班较多，周末偶有临时需求 [来源]
- 可确认：五险一金按实缴 [来源]
- 未查到该公司专属评价
```

明确标出「几条可确认归属」，用户才能判断这部分的可靠程度。
